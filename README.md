# 🐍 Python for Data Analysis & Machine Learning

Jupyter notebooks covering data preparation, statistical modelling, machine learning and NLP, built with **pandas, NumPy, scikit-learn, statsmodels, NLTK, TextBlob, Matplotlib and Seaborn**.

## Projects

| Notebook | What it does | Techniques |
|---|---|---|
| **Sentimental Analysis (Using NLTK) - Airlines** | Scores airline customer reviews and tracks sentiment by year, traveller type and seat comfort | Tokenization, stopword removal, TextBlob polarity, keyword frequency |
| **Takyo Software Case Study Q1** | Predicts whether a customer will make a purchase | Logistic regression, SMOTE oversampling, VIF multicollinearity check, confusion matrix |
| **Takyo Software Case Study Q2** | Predicts customer spending | Linear regression vs. regression tree, RMSE and R² comparison |
| **Decision Tree** | Classifies auctions as competitive or non-competitive and extracts readable decision rules | Decision tree classifier, tree visualization |
| **PCA (Cereals & University Ranking)** | Explores two datasets and reduces their dimensions | Descriptive statistics, histograms, boxplots, principal component analysis |
| **Unsupervised ML** | Groups countries by socio-economic indicators | K-Means clustering, standardization |
| **Toyota Corolla - Partitioning** | Splits data into training, validation and test sets | Train/test split |
| **Normalization** | Rescales features for modelling | StandardScaler, normalization |

## How to run
Open any notebook in Jupyter or [Google Colab](https://colab.research.google.com/) and run the cells from top to bottom.
