# 🐍 Python for Data Analysis & Machine Learning

Jupyter notebooks covering data preparation, statistical modelling, machine learning and NLP, built with **pandas, NumPy, scikit-learn, statsmodels, NLTK, TextBlob, Matplotlib and Seaborn**.

## Projects

| Notebook | What it does | Techniques |
|---|---|---|
| [**Airline Reviews - Sentiment Analysis (NLTK)**](<Airline Reviews - Sentiment Analysis (NLTK).ipynb>) | Scores airline customer reviews and tracks sentiment by year, traveller type and seat comfort | Tokenization, stopword removal, TextBlob polarity, keyword frequency |
| [**Tayko Software - Purchase Prediction**](<Tayko Software - Purchase Prediction.ipynb>) | Predicts whether a customer will make a purchase | Logistic regression, SMOTE oversampling, VIF multicollinearity check, confusion matrix |
| [**Tayko Software - Spending Prediction**](<Tayko Software - Spending Prediction.ipynb>) | Predicts how much a customer will spend | Linear regression vs. regression tree, RMSE and R² comparison |
| [**Decision Tree - Auction Competitiveness**](<Decision Tree - Auction Competitiveness.ipynb>) | Classifies auctions as competitive or non-competitive and extracts readable decision rules | Decision tree classifier, tree visualization |
| [**PCA - Cereals and University Rankings**](<PCA - Cereals and University Rankings.ipynb>) | Explores two datasets and reduces their dimensions | Descriptive statistics, histograms, boxplots, principal component analysis |
| [**K-Means Clustering - Countries**](<K-Means Clustering - Countries.ipynb>) | Groups countries by socio-economic indicators | K-Means clustering, standardization |
| [**Toyota Corolla - Data Partitioning**](<Toyota Corolla - Data Partitioning.ipynb>) | Splits data into training, validation and test sets | Train/test split |
| [**Data Normalization**](<Data Normalization.ipynb>) | Rescales features for modelling | StandardScaler, normalization |

## How to run
Open any notebook in Jupyter or [Google Colab](https://colab.research.google.com/) and run the cells from top to bottom.
